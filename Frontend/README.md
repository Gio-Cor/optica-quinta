# Frontend - Ópticas Quinta

Este es el directorio del Frontend para el sistema de Ópticas Quinta.

Para ver la documentación completa del proyecto (Frontend, Backend, Pasarela de Pagos, Inteligencia Artificial AR y despliegue), por favor revisa el **[README principal del proyecto](../README.md)** en la carpeta raíz.

## Guía Rápida

1. **Instalar dependencias:**
   ```bash
   npm install
   ```

2. **Servidor de desarrollo:**
   ```bash
   npm run dev
   ```

3. **Construcción para producción:**
   ```bash
   npm run build
   ```
